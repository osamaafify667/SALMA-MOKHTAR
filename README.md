# Salma Mokhtar — Premium Portfolio Website 💜

موقع بريميوم 4 صفحات بهوية سلمى (بنفسجي + أسود + أبيض).

## الصفحات
- `index.html` — الرئيسية (معلومات + صورتها + إحصائيات)
- `services.html` — الخدمات بالأسعار + سياسة العمل
- `work.html` — أعمالي (عدادات Upwork/Fiverr + مكان التصاميم)
- `contact.html` — تواصلي معي (فورم بيبعت على واتساب)
- `style.css` + `script.js` — التصميم والحركات

## ⚠️ خطوة مهمة: إضافة صور سلمى
1. احفظي الصورة البنفسجي (الخلفية الموف) باسم: `assets/salma-main.png`
2. الصورة التانية (اختياري) باسم: `assets/salma-2.png`
3. حدّثي الموقع وهي هتظهر تلقائياً في دائرة الهيرو.

## إضافة شغل في صفحة أعمالي
- حطي صور التصاميم في `assets/` بأسماء `work-1.jpg` ... `work-9.jpg`
- في `work.html` بدّلي البلوك الفاضي:
```html
<div class="work-item filled" data-cat="logo"><img src="assets/work-1.jpg" alt="لوجو"></div>
```
- `data-cat` تكون: `logo` / `social` / `brand` / `print`

## خط Shanoy (الإنجليزي)
الموقع مجهز يستخدم خط **Shanoy** في كل النصوص الإنجليزية (اللوجو والعناوين).
بما إنه خط مدفوع ومش متاح مجاناً، حط ملف الخط بنفسك:
1. انسخ ملف الخط في فولدر: `assets/fonts/` بأي اسم من دول:
   `shanoy-regular.woff2` أو `shanoy-regular.woff` أو `shanoy-regular.ttf` أو `Shanoy-Regular.ttf` أو `Shanoy-Regular.otf`
2. اعمل Refresh — الخط هيشتغل تلقائياً.
3. لو الملف مش موجود، الموقع هيستخدم خط بديل شبهه (DM Serif Display) تلقائياً.

الهوية: بنفسجي #8B00FF + أسود #0B0B10، خط اللوجو Shanoy + خط عربي Cairo.
